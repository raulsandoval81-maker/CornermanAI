# Core

Purpose:
Record reality.

Owns:

- Tournament Builder
- Tournament Roster
- Console
- Video Capture
- Match Stats
- Match History

Questions:

- Who wrestled?
- What happened?
- What was the result?

Rules:

Core records reality.

Core does not interpret reality.

Core does not generate recommendations.

Core does not award XP.

Core is the foundation of the Match Engine.
