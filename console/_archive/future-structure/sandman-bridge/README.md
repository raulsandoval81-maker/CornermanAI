# Sandman Integrations

Purpose:
Connect competition data to athlete development.

Owns:

- Weekend Clipboard
- XP Awards
- Athlete Profiles
- Progression
- Placement Awards
- Tournament Bridges

Questions:

- How does this affect the athlete?
- How should XP be applied?
- How should athlete history be updated?
- How should development change?

Rules:

Sandman Integrations consumes Core data.

Sandman Integrations may consume Intelligence data.

Sandman Integrations does not alter match results.

Sandman Integrations does not replace the Match Engine.

Sandman remains the Athlete Development Engine.

Flow:

Core
↓
Intelligence
↓
Sandman Integrations
↓
Athlete Development

Examples:

Match Result
→ XP Award

Tournament Placement
→ Athlete History

Recon Pattern
→ Development Focus

Competition Data
→ Progression Decisions
