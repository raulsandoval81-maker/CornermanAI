System Architecture

Cornerman converts match events into coaching intelligence.

PURPOSE Competition becomes coaching intelligence.

Cornerman is built around one directional flow. Match data is captured first, then preserved, interpreted, and turned into coaching recommendations.

CORE LOOP Match → Event Capture → Match Log → Report → Pattern → Recommendation → Training Focus
CONSOLE Capture

Score the match, record events, preserve video, and save the match payload.

REPORTS Review

Turn saved matches into athlete, team, and match summaries.

PATTERNS Interpret

Identify recurring successes, problems, scoring trends, and coaching signals.

ATHLETES Develop

Build athlete history, strengths, weaknesses, and development context.

EVENTS Organize

Manage tournament context, rosters, match activity, and team performance.

ANALYTICS Measure

Compare scoring trends, team performance, and historical results.

RULE Never reverse the flow.

Reports do not write matches. Patterns do not edit matches. Analytics do not score matches. Each layer has one responsibility.

LONG-TERM QUESTION What happened? Why did it happen? What should we train next?

Everything else is secondary.
