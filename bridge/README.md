# Bridge Layer

## Purpose

The Bridge layer moves reality from capture systems into analysis and development systems.

Bridge does not create data.

Bridge does not analyze data.

Bridge moves data.

---

## Cornerman Doctrine

Capture → Bridge → Analyze → Develop

### Capture

* Console
* Tournament Results
* Match Logs
* Video

### Bridge

* Match Import
* Tournament Import
* Data Sync
* Payload Conversion

### Analyze

* Athlete Dashboard
* Team Dashboard
* Reports
* Recon

### Develop

* Sandman System
* Athlete Development
* XP
* Recommendations
* Training Priorities

---

---

## Rules

Bridge does not score matches.

Bridge does not manage events.

Bridge does not generate reports.

Bridge only moves and transforms data between systems.
